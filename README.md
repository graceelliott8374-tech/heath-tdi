# Heath Telephone & Data

A production full-stack website developed for **Heath Telephone & Data**, an IT and telecommunications services provider.

🌐 **Live Site:** [www.heathtdi.com](https://www.heathtdi.com)

## Overview

This project was built to modernize Heath Telephone & Data's web presence and provide customers with clear access to the company's IT, networking, communications, cybersecurity, and infrastructure services.

The application includes a responsive React frontend and an Express backend supporting customer contact and technical support requests.

## Features

- Responsive desktop, tablet, and mobile design
- Managed IT and network services
- Structured cabling and fiber optics
- Communications services
- Cybersecurity and cloud solutions
- Security and surveillance services
- Contact request system
- Technical support request system
- REST API backend
- Custom production domain

## Tech Stack

**Frontend:** React, Vite, JavaScript, HTML5, CSS3, React Router  
**Backend:** Node.js, Express.js, REST APIs  
**Security & Middleware:** Helmet, CORS  
**Development & Deployment:** Git, GitHub, npm, Insomnia, Vercel
